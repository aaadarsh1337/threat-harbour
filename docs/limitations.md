# Limitations

This project has the following limitations:

- One VM
- One public IP
- One OCI region
- Limited Free Tier CPU, memory, storage, and network capacity
- Cowrie-specific protocol and shell emulation
- No coverage of all Internet services
- Sensor-placement bias
- Public-IP reputation effects
- Possible collection gaps
- GeoIP uncertainty
- No proof of operator identity
- No proof of physical location
- No attacker attribution
- No claim that observed activity represents all Internet activity
- No claim that the sensor stopped or prevented attacks

Geographic enrichment is contextual only. A source IP does not establish the identity, physical location, or intent ofthe operator.
